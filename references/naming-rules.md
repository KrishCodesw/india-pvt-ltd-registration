# Name-check rules

## Suffix
A private limited company's name must end in "Private Limited". If the founder's proposed name doesn't include it, mention it needs to be added — don't just silently append it, since it changes how the name reads and they should own that choice.

## Flagged words (not a full legal list — a practical first pass)
If a proposed name contains any of the following (case-insensitive), tell the founder plainly: not blocked, but this category of name usually needs an extra No-Objection Certificate or regulatory sign-off before MCA approves it, which adds time.

- bank, banking
- insurance
- reserve bank, rbi
- sebi
- stock exchange
- trust
- cooperative, co-operative
- nidhi
- mutual fund
- venture capital
- asset management
- national
- union
- president
- prime minister
- state government
- municipal
- panchayat

## Similarity to existing names
This tool has no live access to the MCA company registry, so it cannot confirm whether a proposed name is already taken or too similar to an existing company/trademark. Always say this out loud: the name is provisional until it's actually run through MCA V3's name-check in Part A of SPICe+. Don't imply a name is "approved" or "clear" based on this conversation alone.
